# 殭屍種蘿蔔大作戰 🥕🧟

一款**完全離線、用手機就能玩**的塔防小遊戲。種下蔬菜，擋住一波波可愛的動物殭屍！
靈感來自「植物大戰殭屍」，但全部用 emoji 畫成，**不需要網路、不用上架、單檔即可遊玩**。

## ✨ 特色

- 📴 **完全離線**：所有畫面用 emoji + Canvas 畫出，沒有任何外部圖檔或連線。
- 📱 **手機操作**：點卡片選蔬菜、點田地種下，純觸控。
- 🥕 **多種蔬菜**：向日葵（產陽光）、蘿蔔、馬鈴薯盾、豌豆連發、辣椒彈、玉米炮、高麗菜、花椰菜王。
- 🧟 **多等級殭屍**：殭屍兔 / 狗 / 貓 / 跳跳蛙 / 鐵盔豬 / 殭屍熊王（魔王）。
- 🗺️ **5 大關卡**：難度漸增，最後一關有魔王戰。
- 🔓 **解鎖系統**：破關自動解鎖新角色。
- 🛒 **商店**：用過關賺到的金幣購買 / 解鎖更多蔬菜。
- 💾 **自動存檔**：金幣、解鎖、過關紀錄都存在手機本機（localStorage），斷網也保留。

## ▶️ 怎麼玩（電腦）

直接用瀏覽器打開 `game/index.html` 就能玩。

## 📱 怎麼放到手機上玩

**方法 A：當網頁玩（推薦，可離線安裝）**
1. 把 `game/` 整個資料夾放到任何靜態網站空間（GitHub Pages、Netlify、或自己的伺服器）。
2. 手機瀏覽器打開網址 → 選單「加入主畫面」。
3. 之後從主畫面圖示開啟，**即使飛航模式也能玩**（Service Worker 已快取）。

**方法 B：完全不靠伺服器**
- 把 `index.html` 傳到手機（AirDrop / LINE 傳檔 / 雲端），用瀏覽器開啟即可。
  （此模式下 Service Worker 會自動略過，但因為遊戲本身就是單檔、無外部資源，照樣離線可玩。）

## 🎮 操作說明

1. 上方卡片是蔬菜，點一下選取（要有足夠 ☀️ 陽光）。
2. 點田地空格種下蔬菜。
3. 🌻 向日葵自動產生陽光；射手類自動攻擊同列殭屍。
4. 🌶️ 辣椒彈炸掉整列；🥔 馬鈴薯盾很硬，拿來擋路。
5. 別讓殭屍走到最左邊的家。清掉所有殭屍即過關，獲得金幣。
6. 右下角 🪏 鏟子可鏟掉種錯的蔬菜。

## 🛠️ 想擴充？

- 新增蔬菜：在 `index.html` 的 `PLANTS` 物件加一筆。
- 新增殭屍：在 `ZTYPES` 物件加一筆。
- 新增關卡：在 `LEVELS` 陣列加一關（含出怪腳本、獎勵、解鎖角色）。
